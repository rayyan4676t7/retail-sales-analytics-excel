# Retail Sales Analysis Using Excel

## Project Overview
This project analyzes retail sales data using Microsoft Excel to evaluate revenue, costs, profitability, and regional and product category performance. It includes data preparation, calculated metrics, summary analysis, and a dashboard for communicating business insights.

## Tools Used
- Microsoft Excel
- Excel formulas and calculated columns
- Summary tables and charts

## Dataset
The dataset contains **180 order records** with retail sales information used to analyze sales performance and profitability.

## Key Performance Indicators

| Metric | Value |
|---|---:|
| Total Sales | ₹17,50,265.50 |
| Total Cost | ₹12,54,550.00 |
| Total Profit | ₹4,95,715.50 |
| Profit Margin | 28.32% |

## Analysis Performed
- Calculated sales, cost, and profit.
- Evaluated overall profitability using profit margin.
- Compared sales performance across regions.
- Analyzed profit contribution by product category.
- Created summary visualizations to communicate results.

## Key Findings
- Total sales were approximately ₹17.50 lakh.
- Total profit was approximately ₹4.96 lakh.
- The overall profit margin was 28.32%.
- The West region recorded the highest sales.
- Storage was the highest-profit product category.
- An `UNKNOWN` category value was identified as a data-quality consideration.
